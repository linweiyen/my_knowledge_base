Agent Pack 研究

Agent Pack（RTX Pack 2.0）是 RTX Pack 的升級版，為小型客戶提供 Docker 單機資源、模型服務及 Agent Container 管理。GDMS 後續整併方向另行規劃；AIDMS 維持多 GPU node 分工。

目前研究

  • 產品規劃啟動會議簡報（10 頁，2026-10-28 修訂）：最新定位、產品替代關係、三種 GPU 配置、工作負載與 image 接入、第一版範圍、驗收與待落實事項。
  • 產品定位：Kick off 討論稿：早期三個方向的討論紀錄，目前定位以啟動會議簡報為準。
  • 全庫閱讀與單機管理系統研究：62 個檔案盤點、架構、現有能力、規格缺口、實測條件與待驗證事項。
  • 完整來源索引：逐檔用途、固定版本連結與雜湊。

核心判斷

Agent Pack 採 Docker、免帳號管理，管理單機 GPU、模型及自製／預整合 Agent Container。GPU 需求包含整卡分配、單卡共享、單容器跨多卡；支援範圍及共享保證需驗證。GitLab 提供工程研究基礎，尚需產品化。

待研究

首發硬體／OS、GPU 共享與多卡模型方案、容器接入規則與相容 image 約定、驗證 image 目錄清單、存取與資料保存、舊產品退場銜接。
